CNN 加速器可视化演示

配套私有主仓库 Soc_riscv32（FPGA 停车车牌识别 SoC）的架构动画，全部纯单文件、可离线打开。
① 层间流水动画层间流水 / PE 阵列 / 权重 ROM
三层同时工作：行缓存 3×3 滑窗 → 9-PE 脉动链 → 权重 ROM 逐拍广播（time_idx）→ 跨拍累加 + ReLU → 输出直送下一层；底部行波前图展示"同一时刻三层处理同一帧的不同行"。
② 滑动窗口 = 缓存行缓存 / 数据复用 / 带宽账簿
每个输入像素被 3×3=9 个窗口复用：输入图每格实时累计复用次数（内部像素涨到 9），行缓存只存最近 3 行、新行挤出旧行，底部实时对比"有缓存 vs 无缓存"的上游读取次数。
源码即本仓库对应 HTML 文件；动画逻辑为教学演示模型，参数以真实 RTL 为原型简化。
