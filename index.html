CNN 车牌识别链路 · 可视化动画系列

配套私有主仓库 Soc_riscv32（FPGA 停车车牌识别 SoC）。按真实数据流排序：①② 在 YOLO 卷积内部，③~⑦ 从 YOLO 输出一路到 CPU。全部纯单文件、可离线打开。
① 层间流水层间流水 / PE 阵列 / 权重 ROM
三层同时工作：行缓存 3×3 滑窗 → 9-PE 脉动链 → 权重 ROM 逐拍广播（time_idx）→ 跨拍累加 + ReLU → 输出直送下一层；底部行波前图展示"同一时刻三层处理同一帧的不同行"。
② 滑动窗口 = 缓存行缓存 / 数据复用 / 带宽账簿
每个输入像素被 3×3=9 个窗口复用：输入图每格实时累计复用次数（内部像素涨到 9），行缓存只存最近 3 行，底部实时对比"有缓存 vs 无缓存"的上游读取次数。
③ YOLO 后处理argmax / sigmoid LUT / 阈值 / 检测包
输出特征图逐格扫描：16 通道 argmax → sigmoid 查表 → 过 CONF_THRESH=64 → 打包 32bit packet + LTRB 共 5 word；无 NMS、无数量上限，大连通区域所有过阈网格全部发包。
④ 坐标还原与裁剪LTRB 解码 / 外扩钳位 / 双线性插值
检测包 → cx=idx×16+8、xmin=cx−L×2 → 外扩+10/+5 → 光栅扫过框区时用定点 DDA 双线性插值，把任意大小的框归一化成 80×20（LPRNet 输入），不存整帧、不碰 DDR。
⑤ 跨时钟传送带异步 FIFO / 逐框轮转 / 黑帧冲刷
每个检测框一条 1600 像素异步 FIFO（video 域写、clk_pe 域读）；半途框作废丢弃；读端逐框轮转加 LINE_GAP；真框读完后补黑帧把 LPRNet 流水线排空，形成帧边界。
⑥ LPRNet 后处理空间求和 / argmax / CTC 解码
末层输出 20×5×128：5 行空间维按列累加 → 每步 128 通道 argmax → CTC greedy（去 blank 75、去相邻重复）把 20 步冗余序列压成 7 位车牌字符索引。
⑦ 结果邮箱跨时钟握手快照冻结 / toggle 同步 / POP 确认
字符压入 64bit 收集寄存器 → result_done 冻结快照 → request_toggle 过两级同步器 → CPU 读 MMIO → 写 POP → ack 回程解锁；演示 CPU 忙时第二包被整包丢弃（dropped+1）。
源码即本仓库对应 HTML 文件；动画为教学演示模型，参数以真实 RTL 为原型简化（网格尺寸、节拍数等均按可读性缩小）。
